# Physical Configuration

Tenant-level physical parameters governing storage, search indexing, relations, crosswalks, streaming and logging.

## Expected files

- `pConfig.json`

## Documentation

https://docs.reltio.com/en/developer-resources/about-developer-resources/developer-resources-at-a-glance/tenant-configuration-parameters-reference

---

This component is not yet managed by Reltio IDE. Files placed here are **not** fetched from or
applied to the tenant; they are version-controlled alongside the configuration so the repository
describes the whole tenant. This file exists because Git does not track empty directories.
