# DTSS

Data Tenant Subscription Service configuration for sharing data from a data tenant into this tenant.

## Expected files

- `dtss_config.json`

## Documentation

https://docs.reltio.com/en/applications/data-integrations/data-enrichment-integrations-at-a-glance/reltio-data-tenant-subscription-service-dtss-at-a-glance

---

This component is not yet managed by Reltio IDE. Files placed here are **not** fetched from or
applied to the tenant; they are version-controlled alongside the configuration so the repository
describes the whole tenant. This file exists because Git does not track empty directories.
