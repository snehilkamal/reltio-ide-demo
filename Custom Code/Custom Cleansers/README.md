# Custom Cleansers

Custom cleanse functions beyond the out-of-the-box address, phone, email, name and string cleansers.

## Expected files

- `One folder or definition file per cleanser`

## Documentation

https://docs.reltio.com/en/objectives/cleanse-and-verify-data/data-cleansing-at-a-glance/data-cleansing-reference/out-of-the-box-cleanse-functions

---

This component is not yet managed by Reltio IDE. Files placed here are **not** fetched from or
applied to the tenant; they are version-controlled alongside the configuration so the repository
describes the whole tenant. This file exists because Git does not track empty directories.
